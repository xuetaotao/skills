## 1. 策略概述

金字塔交易策略并非单一的买入或卖出技巧，而是一套**完整的仓位管理体系**，覆盖从选股、建仓、加仓、做T、减仓到资金调配的全流程。

其核心逻辑是：

- **买入端**：随着价格下跌，逐步加大买入量，形成"底部重、顶部轻"的金字塔结构，有效摊低持仓成本。
- **卖出端**：随着价格上涨，逐步加大卖出量，形成"底部轻、顶部重"的倒金字塔结构，先收回本金和部分利润，逐步做成低成本甚至负成本。
- **中间端**：在震荡行情中通过做T（波段套利）腾出资金和仓位，加固安全边际。

这套体系不是追求"买在最低、卖在最高"——那是不可能的。它的本质是**层层狙击**：当价格进入预设的击球点时果断出手，拿到确定性强的结果，再根据走势调整。市场无法预测，但计划可以提前制定。

### 与传统策略的对比

| 维度 | 金字塔策略 | 一次性买入/卖出 | 网格交易 |
|------|-----------|----------------|---------|
| 建仓方式 | 分批递增 | 一次性全进 | 等量分批 |
| 成本控制 | 强（越跌买越多） | 差（锚定单一价格） | 中（均匀摊薄） |
| 适用行情 | 趋势下跌后反转 | 需精准择时 | 震荡行情 |
| 风险特征 | 下方风险有限 | 单点风险高 | 单边亏损大 |
| 执行难度 | 中（需预设计划） | 低（一锤子买卖） | 中（需持续监控） |

## 2. 核心概念

### 2.1 安全边际

安全边际不仅是买入价格的安全垫，更是一个**三维度综合概念**：

- **资金维度**：保留足够的现金储备（一般不低于总资金的30%），不满仓，给自己留机会。
- **仓位维度**：控制整体仓位在6-7成，极端情况下不超过8成。仓位如开车，满仓是油门踩死易出事，空仓是没启动。
- **成本维度**：通过金字塔加仓和倒金字塔减仓，逐步做低甚至做成负成本，使持仓无惧涨跌。

> "投资先保值，其次才是增值。随着上涨逐步卖出，做低/负成本，做到进可攻退可守。"

### 2.2 负成本持股

通过逢高减仓收回的利润超过剩余持仓的成本，使剩余股票的持有成本变为负数。这是金字塔策略的终极目标之一——一旦做成负成本，持股心态将完全不同：涨了是额外收益，跌了不心疼。

**实现路径**：
1. 金字塔加仓法逢低买入 → 摊低平均成本
2. 反弹后倒金字塔减仓法逢高减仓 → 回收资金和利润
3. 反复几轮后，剩余持仓成本趋近于零甚至为负

### 2.3 击球点

源自巴菲特的投资理念，指**极佳的买入时机或价格点位**。金字塔策略的关键是提前设定好各层击球点，而非临场发挥。当价格触及击球点时，执行既定计划，不带情绪。

### 2.4 防守节点

预设的极端下跌点位。若股价跌破防守节点，则在股价回升到成本线时卖出部分持仓，腾出资金和仓位应对更极端的行情。防守节点是策略的**安全阀**。

## 3. 金字塔加仓法

### 3.1 基本原理

金字塔加仓法的核心是**"越跌越买，越买越多"**。随着股价下跌，买入的数量逐级增加，形成底部宽、顶部窄的金字塔形状。

**数学优势**：

| 操作 | 价格 | 买入数量 | 累计投入 | 累计股数 | 平均成本 |
|------|------|---------|---------|---------|---------|
| 第1次 | 100元 | 30股 | 3,000 | 30 | 100.00 |
| 第2次 | 90元 | 50股 | 7,500 | 80 | 93.75 |
| 第3次 | 80元 | 80股 | 13,900 | 160 | 86.88 |
| 第4次 | 70元 | 120股 | 22,300 | 280 | 79.64 |

从100元跌到70元，跌幅30%，但通过金字塔加仓，平均成本降至79.64元。**只需反弹回80元即可实现账面浮盈**，而不需要回到100元的起始位置。

### 3.2 资金分配比例

作者常用的核心资金分配比例为：

```
1 - 1 - 1.5 - 2 - 2 - 2.5
```

对应6个买入节点，资金从少到多逐步增加。解读：

- **前两次（1:1）**：小跌小买，试探性建仓，各分配约10%的计划资金
- **中间两次（1.5:2）**：中等跌幅加大买入，各分配15%-20%的计划资金
- **最后两次（2:2.5）**：大跌大买，重仓出击，各分配20%-25%的计划资金

**另一种宽基ETF常用比例**：

```
1 - 1 - 1.5 - 1.5 - 2 - 2 - 3
```

最后的"3"动用额外资金（如从防御型资产套现），属于"大跌大买"的极端情况。

### 3.3 个股买入参数设定

#### 首发建仓触发条件

- **普通优质公司**：基本面未恶化前提下，从高点下跌 **30%** 左右开始买入
- **极优质公司**（"第一兼唯一"）：下跌 **20%+** 即可动手

#### 加仓间距

| 投资者类型 | 档差建议 | 说明 |
|-----------|---------|------|
| 资金有限者 | 8% - 15% | 档差拉大，确保每次加仓有足够价差意义 |
| 资金充裕者 | 4% - 6%（约5-20美元/档） | 小步快跑，更精细地摊低成本 |
| 极端高波动股 | 15% - 20% | 如特斯拉等，需放大幅差避免过早打完子弹 |

> **原则**：结合自身资金情况设定，适合自己的才是最好的。

#### 买入次数

- 设置量一般 **≥ 6次**，绝不能两三次就打完所有子弹
- 资金至少分5次，从少到多逐步建仓，不贪多、不急躁

### 3.4 宽基指数ETF买入参数

| 标的 | 首发建仓触发 | 加仓间距 | 买入次数 |
|------|------------|---------|---------|
| 标普500（VOO/SPY） | 跌幅达 **6.5%+** | 每跌 **2.5%-3%** | ≥ 6次 |
| 纳指100（QQQ） | 跌幅达 **9%+** | 每跌 **3.5%** | ≥ 7次 |

### 3.5 大盘指数资金分层分配（以纳指为例）

不主观猜底，按下跌幅度分层分配资金：

| 下跌区间 | 资金分配 | 累计投入 |
|---------|---------|---------|
| 17500 - 16500点 | 约10% | 10% |
| 16500 - 15500点 | 约20% | 30% |
| 15500 - 14500点 | 约30% | 60% |
| 14500点以下（超卖） | 约40% | 100% |

还可以从美债/防御型资产套现调配额外资金。

## 4. 倒金字塔减仓法

### 4.1 基本原理

倒金字塔减仓法是金字塔加仓法的镜像——**随着股价上涨，卖出数量逐渐增加**，先少量卖出试探，后大量卖出锁定利润。

**核心目标**：
1. 先收回本金和部分利润，落袋为安
2. 剩余利润继续持有，享受可能的进一步上涨
3. 通过多轮操作，逐步做成低成本/负成本

### 4.2 "2-3-3-2"四阶段卖出法

以持仓成本82元的英伟达为例：

| 阶段 | 涨幅区间 | 卖出比例 | 操作方式 |
|------|---------|---------|---------|
| **第一阶段** | 上涨30%-50%（107-123元） | 总仓位的20% | 分3-4次卖完，每次5%-10% |
| **第二阶段** | 上涨50%-80%（123-148元） | 总仓位的30% | 分3-4次卖完 |
| **第三阶段** | 继续上涨 | 总仓位的30% | 此阶段通常已为负成本，选择持有等创新高 |
| **第四阶段** | 创新高后 | 总仓位的20% | 看情况落袋为安 |

> 后两阶段（合计50%仓位）由于已经实现负成本，通常选择继续持有等待创新高，除非出现明显的见顶信号。

### 4.3 实战卖出节点示例

**台积电**：
- 190美元卖5%，195美元卖5%，200美元卖5%，210美元卖5%（合计完成第一阶段20%）
- 215美元卖5%，220美元卖5%，225美元卖10%（进行第二阶段30%）

**Meta**：
- 720美元卖5%，725美元卖5%，730美元卖10%（完成第一阶段20%）
- 735美元卖10%（740和750的卖点未成交即下跌，说明卖出节奏也需要灵活调整）

### 4.4 倒金字塔减仓的核心原则

1. **先做确定性强的操作**：当目标进入击球点时先击球，不要等"更好的价格"
2. **分批执行**：每次只卖一部分，防止卖飞后踏空
3. **70%底仓不动**：大部分仓位做长期持有，只用30%做波段
4. **新高不加仓**：上涨过程中绝不追高加仓，只做减仓操作

## 5. 做T策略

### 5.1 什么是做T

做T即在持股期间通过日内或短期波段交易进行高抛低吸，主要目的：

1. **首要目的**：腾出资金和仓位（为后续下跌时能继续抄底加固安全边际）
2. **次要目的**：降低持仓成本

### 5.2 仓位分配

| 投资者水平 | 底仓比例 | 做T仓位 |
|-----------|---------|---------|
| 一般投资者 | 7成 | 3成 |
| 技术高手 | 5-6成 | 4-5成 |

### 5.3 两种做T方式

#### 正T（先买后卖）

- **适用**：预计股价短期下跌后反弹
- **操作**：先在低位买入 → 反弹后保本或微利卖出 → 腾出资金
- **推荐程度**：★★★★★（作者提倡，适合大多数投资者）

#### 反T（先卖后买）

- **适用**：预计股价短期下跌
- **操作**：先在高位卖出部分 → 低位买回赚差价
- **推荐程度**：★★★（考验技术，不适合新手，容易卖飞底仓）

### 5.4 做T的适用场景

| 行情 | 是否做T | 说明 |
|------|--------|------|
| 震荡行情 | ✅ 适合 | 高抛低吸的理想环境 |
| 单边上涨 | ❌ 不做 | 做T容易卖飞，踏空损失远大于做T收益 |
| 单边下跌 | ⚠️ 谨慎 | 可做正T，但需控制节奏 |
| 仓位资金充足 | ❌ 可不做 | 无资金告急则无需做T，持有即可 |

### 5.5 做T的纪律要求

1. **必须留够底仓**，防止卖飞后无法接回
2. **设置好指令后少看盘**，避免看着行情临时冲动操作
3. 一般设置**盘中交易**；盘前多观察，除非价格极具诱惑力跌到预期，否则不临时操作
4. 如果没忍住临时买了一点，只买极少量的满足操作欲，不影响整体计划

## 6. 仓位管理与资金调配

### 6.1 日常仓位控制

- **常规仓位**：6-7成
- **警戒线**：突破8成需进行"投资再平衡"——套现部分转向防御型资产
- **最低备用金**：不低于总资金的30%
- **极少超过8成仓**

> "仓位如安全带，永远不满仓，给自己留机会。满仓是油门踩到底，出了事没有缓冲。"

### 6.2 账户架构

| 账户类型 | 持仓内容 | 目标 |
|---------|---------|------|
| **进取型账户** | 科技巨头等高成长个股 | 追求超额收益 |
| **稳健型账户** | 宽基ETF + 消费龙头 + 医药龙头 | 稳健增值 |
| **防守型账户** | 国债 + 国债ETF + 伯克希尔 + 高息股 | 资金安全垫 |

**核心逻辑**：资金体量越大，防守型和稳健型资产越有必要。靠运气赚的钱，应放到不靠运气也能赚钱的地方。

### 6.3 资金调配体系

资金的调配和投资加仓整体是一个**可循环、相互协调、流动性强弱相关**的体系，如同行军打仗（涉及粮草储备、后方支援、各军调配）：

```
┌──────────────────────────────────────────────────┐
│                   资金调配体系                      │
│                                                    │
│  日常现金流 ──→ 进取型账户（大跌时加仓）              │
│       │                                            │
│       ├──→ 稳健型账户（配置宽基+消费+医药）           │
│       │                                            │
│       └──→ 防守型账户（国债+高息股+伯克希尔）         │
│                  │                                  │
│                  └──→ 大跌时套现增援进取型账户         │
│                                                    │
│  防御型产品变现规则：                                │
│  · 短期（变现容易）→ 优先变现                        │
│  · 中期（变现一般）→ 次优先                         │
│  · 长期（能创造现金流）→ 最后变现                    │
└──────────────────────────────────────────────────┘
```

### 6.4 投资再平衡

当仓位突破8成时，执行投资再平衡：

1. 套现部分涨幅较大的持仓
2. 转向配置防御型资产（国债、高息股等）
3. 增厚资产"安全垫"
4. 为下一次大跌储备子弹

## 7. 凯利公式的应用

### 7.1 公式简介

凯利公式（Kelly Criterion）是仓位管理的数学基础，其连续形式为：

```
f* = (μ - r) / σ²
```

其中：
- **f***：应投入风险资产的最优资金比例
- **μ**：风险资产的预期收益率
- **r**：无风险利率（如国债利息）
- **σ²**：风险资产收益率的方差（代表风险）

**本质**：超额收益 / 风险。优势越大、风险越小，下注比例应越大。

### 7.2 凯利公式的三大思维框架

#### 框架一：有优势时下注，无优势时观望

- f*为负或零时不下注
- **操作体现**：几乎不追高疯涨的个股，没有击球点不出手

#### 框架二：优势越大下注越重，但永远不押全部

- 高胜率、高赔率时可重仓，但绝不满仓
- **操作体现**：大暴跌中分批买入，但始终保留备用金

#### 框架三：风险（波动）是下注的敌人

- 波动大会引发恐惧，让人不敢在低位买入
- **操作体现**：做低成本/负成本，构筑防守型资产，保持良好心态

### 7.3 半凯利策略

因现实中精确估计胜率和赔率极其困难，人通常**高估胜率**，专业投资者常使用"半凯利"策略：

```
实际下注比例 = f* / 2
```

牺牲少量增长率，大幅降低波动和破产风险。这与金字塔策略中"不满仓、分批建仓"的理念完全一致。

### 7.4 凯利公式与金字塔策略的融合

| 凯利原则 | 金字塔策略体现 |
|---------|---------------|
| 有优势时下注 | 只在基本面优质的"第一兼唯一"标的上使用 |
| 优势大下注重 | 大跌时加大买入量（金字塔递增） |
| 永远不押全部 | 保留30%+现金，6-7成仓位 |
| 风险是敌人 | 做低成本/负成本，构建防守资产 |

## 8. 选股原则与击球点

### 8.1 "第一兼唯一"选股原则

- **"第一"**：行业内规模最大、市场地位最高的龙头公司
- **"唯一"**：具有不可替代核心竞争力的公司
- **最好兼具**：既有规模地位，又有不可替代性

> "选择不对，努力白费，选择比努力重要。"

### 8.2 基本面分析框架

#### "三表"分析

| 报表 | 看什么 | 核心判断 |
|------|-------|---------|
| 利润表 | 是否赚钱及成长性 | 营收和利润趋势 |
| 资产负债表 | 公司是否健康 | 现金是否覆盖刚性债务 |
| 现金流量表 | 钱的真伪 | 经营现金流为正较真实 |

#### 行业前景三要素

1. **市场空间**：天花板有多高
2. **政策利好和风向**：是否站在风口
3. **竞争优势**：护城河有多深

### 8.3 市盈率（PE）参考

PE只是参考工具，不是直接答案：

- **纵向对比**：与自身历史PE比（如原波动区间10-30倍，低于15偏低可高看，高于35偏高）
- **横向对比**：与同行业对手比（如英伟达vs博通/AMD），跨行业无对比意义

| 行业 | 典型PE区间 |
|------|-----------|
| 银行 | < 10 |
| 白酒/医药 | 20-25 |
| 科技 | 25-100+ |

### 8.4 MACD辅助判断

适合用MACD的：蓝筹股、大盘股、成熟行业龙头股。不适合：高波动性股票、小盘股、新股或次新股。

作者习惯用参数 **(6, 13, 5)**，比默认 (12, 26, 9) 更灵敏、滞后性更小。

| 信号 | 判断 |
|------|------|
| DIF线和DEA线同为正数且DIF上穿DEA | 买入信号 |
| MACD柱由绿变红 | 买入信号 |
| DIF线和DEA线同为负数且DIF下穿DEA | 卖出信号 |
| MACD柱由红变绿 | 卖出信号 |
| DEA线和股价背离 | 变盘信号 |

| 限制 | 金字塔策略适配 |

| **存量资金市场** | 资金博弈特征明显，需更注重左侧交易（提前埋伏） |

## 12. 常见误区与风控红线

### 12.1 六大常见误区

#### 误区一：倒金字塔加仓（越跌越买越少）

这是最致命的错误。在顶部大量买入，底部反而不敢加仓：

```
❌ 错误示范（倒金字塔加仓）：
100元买1000股 → 90元买500股 → 80元买200股 → 70元买100股
成本 = 91.8元，股价需要反弹31%才能回本

✅ 正确操作（正金字塔加仓）：
100元买100股 → 90元买200股 → 80元买500股 → 70元买1000股
成本 = 76.7元，股价只需反弹9.5%即可回本
```

#### 误区二：两三次就打完所有子弹

没有耐心，急于建仓。应该在5-6个甚至更多节点分批买入。

#### 误区三：追高加仓

上涨过程中加仓，违反金字塔原则。上涨只做减仓，不做加仓。

#### 误区四：不做防守节点

没有预设极端情况下的应对方案，一旦超预期下跌就手足无措。

#### 误区五：满仓操作

不留备用金，一旦出现更好的机会无法出手。满仓带融资更容易在暴跌中爆仓。

#### 误区六：在单边上涨行情做T

做T容易卖飞，踏空损失远大于做T收益。

### 12.2 风控红线

| 红线 | 说明 |
|------|------|
| **绝对不满仓** | 至少保留30%备用金 |
| **绝对不上杠杆**（普通人） | 杠杆放大风险，一次失误可能致命 |
| **绝对不追高** | 上涨只做减仓，不做加仓 |
| **绝对不做不懂的标的** | 不了解就不碰，错了也不知道错在哪 |
| **单只个股仓位不超过总仓位15%** | 分散风险，避免单一个股黑天鹅 |
| **跌破防守节点必须执行纪律** | 回升到成本线时卖出部分，不抱幻想 |

## 13. 策略回测验证框架

如果要验证金字塔交易策略的回报率、回撤与夏普比率，需要关注以下回测维度：

### 13.1 核心回测指标

| 指标 | 计算方式 | 意义 |
|------|---------|------|
| **年化收益率** | (期末净值/期初净值)^(252/交易日) - 1 | 策略整体回报 |
| **最大回撤** | max((峰值-谷值)/峰值) | 最坏情况下的亏损幅度 |
| **夏普比率** | (年化收益-无风险利率) / 年化波动率 | 每承担一份风险获取的回报 |
| **卡尔玛比率** | 年化收益 / 最大回撤 | 回撤成本效率 |
| **胜率** | 盈利交易次数 / 总交易次数 | 交易的准确性 |
| **盈亏比** | 平均盈利 / 平均亏损 | 单次交易的风险收益比 |
| **Alpha** | 策略收益 - 基准收益 × Beta | 超额收益 |
| **Beta** | 策略收益与基准收益的协方差 / 基准方差 | 市场敏感度 |

### 13.2 场景分析维度

1. **牛熊周期分析**：按市场阶段（牛市/熊市/震荡市）分段统计各指标
2. **参数敏感性**：扫描加仓间距（4%-15%）、资金比例（1-1-1.5-2-2-2.5 vs 其他）等参数
3. **蒙特卡洛模拟**：随机打乱交易顺序，观察收益分布
4. **压力测试**：在极端行情（2015股灾、2020疫情、2022加息）下的表现

### 13.3 回测避坑要点

| 坑 | 说明 |
|----|------|
| **前视偏差** | 当天信号只能次日执行，不能"偷看"未来数据 |
| **存活偏差** | 回测要用历史成分股，不是现在的成分股 |
| **过度拟合** | 参数调到完美但不具泛化性，务必做样本外检验 |
| **忽略交易成本** | 滑点+佣金+冲击成本，长期影响很大 |
| **T+1限制** | A股当天买入不能当天卖出 |

## 14. 总结：策略闭环

金字塔交易策略的完整操作闭环：

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  ① 选股：基本面优质 + "第一兼唯一" + 行业前景              │
│     ↓                                                       │
│  ② 设定击球点：提前规划6+个买入节点和资金分配               │
│     ↓                                                       │
│  ③ 金字塔加仓：逢低买入，越跌买越多（1-1-1.5-2-2-2.5）     │
│     ↓                                                       │
│  ④ 做T（震荡行情）：高抛低吸，腾出资金和仓位                │
│     ↓                                                       │
│  ⑤ 倒金字塔减仓：逢高卖出，越涨卖越多（2-3-3-2）           │
│     ↓                                                       │
│  ⑥ 做成低成本/负成本 → 持股无惧涨跌                        │
│     ↓                                                       │
│  ⑦ 投资再平衡 → 套现部分 → 配置防守型资产 → 储备子弹       │
│     ↓                                                       │
│  ⑧ 等待下一次大跌 → 回到步骤 ③                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 核心心法

1. **不满仓就是给自己留机会** —— 准备好资金仓位，带着耐心和勇气等待机会
2. **只做看得懂的交易** —— 不懂不碰，错了能知道错在哪
3. **先做确定性强的事** —— 进入击球点就出手，不要追求完美
4. **市场不言底** —— 新手才妄图精准狙击底部，老手靠计划层层狙击
5. **万物皆周期** —— 在春风得意时布局，平淡了才有退路
6. **追求长期可持续** —— 相比短暂辉煌，更追求"长期可持续的循环体系"

> "富在术数，不在劳身；利在势局，不在力耕。" —— 《盐铁论》
