# 卡包记 · 信用卡年费管理小程序(MVP · 纯本地版)

记录信用卡信息,自动推算年费周期,在仪表盘上高亮临期未达标的卡片,避免遗忘。

**本版本为「纯本地存储」**:数据只存在你手机本机,**不依赖任何云服务、不需要服务器、没有任何月度费用**。

> 提醒方式说明:小程序关掉即停止运行,无法后台主动推送。所以本版的「提醒」是——**打开 App 时,仪表盘自动高亮临期/未达标的卡片**。如果你以后想要「关掉 App 也被微信推送」,再开启云开发即可(见末尾)。

## 三、使用

- **新增卡片**:点右下角「+」→ 填银行/类型/启卡日期/年费/减免条件等 → 保存。
- **查看 / 编辑 / 删除**:点列表里的卡片进入详情页。

## 四、数据说明(重要)

数据保存在本机 `wx.storage`(key = `cards`)。**它不跟随微信账号、不跨设备同步**,因此以下情况会导致数据清空或丢失:

### ❌ 会清空本地数据(wx.storage)的情况

| 场景 | 说明 |
|---|---|
| **换手机 / 新设备登录微信** | 本地存储不跟随微信账号,新手机上是空的 |
| **卸载微信 App** | 全部丢失 |
| **手机系统清除微信数据** | Android:设置 → 应用 → 微信 → 清除数据;iOS:卸载微信重装 |
| **微信内清理小程序缓存** | 我 → 设置 → 通用 → 存储空间 → 小程序 → 清理 |
| **微信整体清理缓存** | 我 → 设置 → 通用 → 存储空间 → 清理缓存 |
| **存储严重不足时** | 极少数情况,系统/微信可能回收小程序本地存储(非 100% 永久保障) |
| **代码主动全清** | 若以后写了 `wx.clearStorage` 全删(当前代码未调用,删除卡片只删单条) |

### ✅ 不会清空的情况(可放心)

| 场景 | 说明 |
|---|---|
| 关闭小程序再打开 | 数据在 |
| **上传新版本 / 设体验版 / 更新** | 本地存储保留,数据不丢(升级 App 不会清掉已录的卡) |
| 从「最近使用」列表移除小程序 | 一般只移除列表项,不删数据 |
| 杀进程、手机重启 | 数据在 |

### 备份建议
- 纯本地版最大的短板是**换机 / 清缓存会丢**。后续版本(P3)计划加「导出 / 备份」功能。
- 平时**勿手滑点「清理小程序缓存」**。
- 数据仅你自己可见,不与家人共享(如需共享,需改用云开发,见末尾第八节)。

## 五、运行与发布(含随时更新)

小程序没有「刷新即生效」,而是「上传即分发」。下面三种用法按需选。

### 1. 真机调试(临时、最快)
- 开发者工具 → 点「**预览**」→ 出临时二维码 → 微信扫码即在真机跑最新代码。
- 适合边改边测。**预览码有时效**,长期用请走下面的体验版。

### 2. 自用发布(体验版 · 推荐)
免备案、免审核、免上线,自己和家人像正常小程序一样用。

1. **补全小程序基础信息**(如未填):登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 设置 → 基本设置 → 名称(中性,如「卡包记」)、类目选「工具」、传图标。
2. **上传**:开发者工具 → 顶部「**上传**」→ 填版本号(如 `1.0.0`)和备注 → 确定。
3. **设为体验版**:后台 → 管理 → 版本管理 → 找到刚上传的版本 → 点「**设为体验版**」。
4. **加体验成员**:后台 → 成员管理 → 体验成员 → 添加你自己的微信(家人同理)。
5. **扫码使用**:用微信扫体验版二维码 → 即可使用,**不用备案、不用审核**。

### 3. 随时更新(像 Web 一样自由,只是「刷新」换成「重开」)
改完代码后:

1. 开发者工具改代码 → 点「**上传**」→ 填新版本号(如 `1.0.1`)。
2. 后台把新版本「**设为体验版**」(覆盖旧的)。
3. 你和家人**关掉小程序重新打开** → 即拿到新版。

- 体验版更新**无需审核**,随时可发。
- 生效不是即时的:通常几分钟内、或下次启动生效。若对方重开还是旧的,让他**彻底退出小程序(微信最近使用里划掉)再进**,基本能强制拉到新版。
- 自己快速验证改动,优先用第 1 步的「预览」二维码。

### 4. 全网发布(给陌生人用才需要)
只有想让不特定外人也能搜到/使用时才需要:体验版 → 提交审核 → **备案**(ICP) → 正式上线。
自用场景**永远用不到这步**,也无需备案、无需服务器。

> 小结:自用 = 上传 + 设体验版 + 扫码,随时能更新;正式发布才要审核+备案。

## 六、数据模型(cards,本机数组)

| 字段 | 说明 |
|---|---|
| `id` | 本地唯一 id(自动生成) |
| `bank` | 银行(选择器) |
| `cardType` | 卡片类型(普卡/金卡/白金…) |
| `cardLast4` | 卡号后 4 位(区分同名银行的卡) |
| `creditLimit` | 额度 |
| `activationDate` | 启卡日期 `YYYY-MM-DD`(年费周期按此推算) |
| `annualFee` | 年费金额 |
| `waiverType` | 减免类型:`count`(笔数)/ `amount`(金额)/ `none`(必缴)/ `manual`(手动) |
| `waiverTarget` | 减免目标值 |
| `waiverProgress` | 当前进度 |
| `billingDay` / `repaymentDay` | 账单日 / 还款日(几号) |
| `remarks` | 备注 |
| `createdAt` / `updatedAt` | 自动管理(时间戳) |

年费周期按启卡日期推算(如 3/15 启卡 → 每年 3/15~次年 3/14),到期自动滚动,无需手动维护。

## 八、如果以后想要「关掉 App 也推送提醒」

纯本地版做不到后台推送(平台限制)。若需要,可升级为云开发版:

1. 开通云开发,建集合 `cards`,迁移本地数据。
2. 加一个定时云函数,每天检查临期未达标卡片,通过**订阅消息**推送到微信。
3. 个人主体只能用「一次性订阅」(每次打开 App 授权一次积累配额);企业主体可申请「长期订阅」。

> 升级会引入云开发费用(现行:新用户 6 个月免费,之后免费体验版 0 元/月或 个人版 19.9 元/月)。是否值得,取决于你对「主动推送」的刚需程度。
