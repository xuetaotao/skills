# 周期行业观测台

跟踪有色金属、能源（原油 + 煤炭）、航运三个周期板块：自动抓取价格、库存、供给、运价和板块股票指数，判断每个板块**现在处在周期的哪个位置、正往哪个方向走、接下来该关注什么**，通过本地网页查看。

## 快速开始

1. 安装依赖（只需一次）：

   ```bash
   pip install -r requirements.txt
   ```

2. 双击 `scripts/start_server.bat`。服务就绪后会自动打开浏览器访问 <http://127.0.0.1:8321>。关闭命令行窗口即停止服务。

3. 第一次打开会有 4 步使用指引，之后随时可以点右上角的「?」重新查看。

- **首次运行**会自动下载十几年的历史数据（约 2–5 分钟），页面显示进度，完成后自动进入总览。
- **每次启动**都会在后台自动增量刷新，页面顶部显示“刷新中 x/42”，完成后自动更新结论。不想自动刷新时，先设置环境变量 `CYCLE_AUTO_REFRESH=0` 再启动。
- 随时可以点顶栏的「刷新数据」手动更新。

页面必须通过上面的地址访问，直接双击 `frontend/index.html` 取不到数据。

启动脚本使用项目内的 `.venv`。还没有时，用 PATH 上的 `python` 创建并安装依赖。已有环境但缺少依赖时，脚本会提示安装命令。

## 页面

- **总览**：今日结论、周期轮盘（三个板块在周期中的位置）、三张板块卡片（温度、阶段、与上月相比的变化、决策提示、主要信号），以及按重要程度排序的“需要关注”信号。
- **有色金属 / 能源 / 航运**：板块结论和决策提示；各分组（如能源 = 原油 + 煤炭）的温度和可信度；信号列表；股商对照摘要；全部指标卡片（最新值、数据日期、近一年走势、历史分位、1 月 / 3 月 / 1 年涨跌）。点任意卡片可以查看走势图，支持 1 / 3 / 5 / 10 年和全部历史，可叠加分位线、显示已剔除的坏点、查看数据表。
- **股商对照**：商品价格与板块股票指数的双轴走势，背离区间以红色底色标出，下方是 60 日滚动相关系数，并自动生成结论（近 60 日涨跌对比、当前与历史平均相关性、是否处于背离区间）。也可以自选任意两个指标对照。
- **数据健康**：每个指标的数据源、起止日期、滞后天数、剔除的坏点，可以筛选出有问题的指标。
- **术语**：分位、周期温度、去库 / 累库、BDI 分船型等术语的白话解释。正文中带虚线下划线的词悬停即可查看。
- **报告**：浏览 `reports/` 下留存的研判报告。

## 判断口径

- **分位**：最新值在近 10 年（不足 10 年按实际年限，页面会标注）所有数据中的百分位。
- **动量与趋势**：最新值相对 1 / 3 / 6 / 12 个月前的涨跌幅。近 3 个月涨跌超过 ±3% 视为上行或下行，否则为走平。
- **周期温度（0–100）**：分组内核心价格的分位平均；板块温度是各分组温度的平均。先分组再平均，避免某类品种数量多就主导结论：

  | 板块 | 分组与核心价格 | 辅助指标 |
  |---|---|---|
  | 有色金属 | 铜（沪铜、LME 铜）、铝（沪铝、LME 铝） | LME 铜 / 铝库存，申万有色指数 |
  | 能源 | 原油（WTI 现货、布伦特现货、上海原油 SC）、煤炭（动力煤现货基准价、焦煤） | 美国商业原油库存、美国原油产量，申万煤炭指数 |
  | 航运 | 干散货（BDI）、油运（BDTI） | BCI / BPI / BSI 分船型，申万航运港口指数 |

  黄金、白银、锌、镍、COMEX 铜、WTI / 布伦特期货等只作参考，不计入温度。
- **周期阶段**：温度 ≥ 80 为高位，< 25 为低位，结合 3 个月趋势分为七个阶段，按周期顺序为：低位寻底 → 低位回升 → 上行中段 → 高位强势 → 高位回落 → 下行中段 → 低位寻底；位置居中且方向不明时为中位震荡。每个阶段附带一条决策提示。
- **信号**：
  - 价格与库存的配合：价涨库降、价涨库增、价跌库增、价跌库降；库存处于历史极低或极高位。近 3 个月库存变化超过 ±10% 算去库 / 累库，美国原油库存波动小，取 ±5%。
  - 供给处于历史高位（如美国原油产量）。
  - 组内分化（如 WTI 与布伦特走势差距大）、干散货分船型分化。
  - 股商背离：近 60 个交易日商品与板块股票方向相反，或涨跌幅相差 10 个百分点以上；两者相关性跌破 0.2。
  - 阶段变化：与一个月前相比阶段改变（温度变化不足 5 且趋势未变的小幅跳动不算）。
- **数据质量**：
  - 日度数据超过 10 天、周度超过 21 天没有更新视为过期，只展示，不参与温度、阶段和多数信号。
  - 历史不足 3 年的价格只参与动量，不参与温度。
  - 坏点剔除：相对上一个有效值偏离 40% 以上、且随后 3 个点内又回到原水平 10% 以内的点，判定为数据源错误，分析时剔除，数据库保留原值。运价指数不做剔除。

这些规则是对“位置 + 方向”的统计刻画，帮助快速定位和发现异常，不能替代对供需基本面的判断。

## 项目结构

```
stock/cycle_tracking/
├── backend/                  # 后端（Python 包）
│   ├── config.py             # 指标注册表（42 个序列的数据源、角色、频率）与板块分组结构
│   ├── fetchers.py           # 取数层：每个数据源显式指定日期列和数值列
│   ├── db.py                 # SQLite 读写
│   ├── update.py             # 数据更新：增量 / 全量 / 指定指标，带数据校验
│   ├── analyzer.py           # 分析引擎：分位、动量、坏点剔除、温度、阶段、信号
│   ├── server.py             # FastAPI 服务：页面、数据 API、后台刷新
│   └── glossary.py           # 术语词条
├── frontend/                 # 单页应用（index.html / app.js / style.css）
│   └── vendor/echarts.min.js # 图表库（本地存放，不依赖外网 CDN）
├── scripts/
│   ├── start_server.bat      # 双击启动
│   ├── update_data.bat       # 双击增量更新数据（不启动网站）
│   └── probes/               # 建项时的数据接口实测脚本，排查数据源时参考
├── docs/                     # 建设规划文档（2026-09-19）
├── reports/                  # 研判报告
├── data/                     # cycles.db 数据库（已 gitignore）；手动补录的 manual.csv
└── requirements.txt
```

命令行用法（在本目录下）：

```bash
python -m uvicorn backend.server:app --port 8321   # 启动网站
python -m backend.update                           # 增量更新全部指标
python -m backend.update BDI WTI                   # 只更新指定指标
python -m backend.update --full                    # 全量重建（会先清空已有数据，慎用；SCFI 这类累积型指标不清空）
```

## 手动补录

`SCFI`（集装箱运价指数）每次刷新自动从上海航运交易所抓取最近两期，但官方不提供更早的历史。需要补历史时写入 `data/manual.csv`，表头为 `code,date,value`：

```csv
code,date,value
SCFI,2026-10-09,3650.2
```

下次刷新时会与自动抓取的数据合并（同一天以官方接口为准）。

## 数据局限

- **动力煤**：现货基准价 2025-08 起才有日度数据，只参与动量，不参与温度；秦港 Q5500 只有 2021-06 至 2022-02 的历史档案。实测过的免费源（AKShare 现货价、99 期货网、各期货库存接口）都没有更长的动力煤现货历史，只能等数据自然积累，大约 2028 年满 3 年后自动参与温度。
- **SCFI**：官方接口只给最近两期，历史从 2026-10 开始累积，约一年后才有足够数据计算分位，在此之前只展示，不计入温度。
- **航运股票对照**：申万航运港口指数 2021-12 起，成分以集运、油运和港口为主，与 BDI 几乎不相关，所以股商对照用油运指数 BDTI（历史周收益相关约 0.3），相关性仍然偏弱，参考价值有限。
- **库存只有海外口径**：LME 库存和美国商业原油库存都是海外数据。国内的上期所库存只能从东方财富取到 2026-07 以后的数据，暂未接入。
- 数据接口偶尔会失效或改版，刷新失败的指标会在页面提示和「数据健康」中列出。Westmetall、EIA 官网、上海航运交易所是网页抓取，改版时需要调整 `backend/fetchers.py`（实测脚本见 `scripts/probes/probe_13.py`）。
