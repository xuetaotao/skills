# 鱼盆复盘

用**鱼盆模型**（收盘价在 20 日均线之上为 YES、之下为 NO）跟踪全球主要股指、大宗商品和几个 A 股行业指数、个股，同时看美元指数、中美国债收益率和指数估值，每周给 AI 一份整理好的素材，生成「鱼盆模型周度复盘」。

本地运行的小网站：双击启动，每次启动时自动更新数据。除了当天的状态，还能看**本周和上周比有什么变化**、近几周的偏离度走势、任一标的的完整历史，以及回看任意一周当时的样子。原来的 yupen 日报（多 Agent 脚本）已经合并进来：它的标的、5 档信号、PE 百分位都在这里，GitHub Pages 上的日报也改由本项目生成（见下文「GitHub Pages 日报」）。

## 快速开始

```bat
scripts\start_server.bat
```

脚本会启动服务并自动打开 <http://127.0.0.1:8325>。首次运行会下载 36 个标的 2015 年以来的日线、美元指数、中美国债收益率和蛋卷估值，大约 40 秒，页面会显示进度，完成后自动进入总览。之后每次启动都会在后台更新一次（40 秒左右），同时重写 `outputs/latest_review*.md/html`；运行期间可随时点右上角「刷新数据」。

启动脚本使用项目下的 `.venv`。还没有这个目录时，用 PATH 上的 `python` 创建它并安装 `requirements.txt`，之后一直用这个环境。已有 `.venv` 但缺少依赖时，脚本会提示安装命令：

```bash
pip install -r requirements.txt
```

Linux / macOS 用 `bash scripts/start_server.sh`。

## 页面

| 页面 | 用途 |
|------|------|
| 总览 | 精简版 / 完整版切换；汇总（股市、商品各有几个 YES，本周转为 YES / NO 的标的，美元指数和美债 10 年的本周变化）；按市场分组的一句话小结；股市、大宗商品两张表，按偏离度由强到弱排序，列出现价、当日涨跌、本周涨跌、临界值、状态和 5 档信号、偏离度、PE 百分位（有估值的指数）、状态持续天数、近 60 日偏离度小图；今日转变、本周转变的行有橙色底色和标记；完整版另有「行业与个股」表（单独排名，不计入 YES 统计）；美元指数和中美国债卡片。可**回看**任意一周（下拉选周末日期），也可以「编辑精简版」「截图版」（打开周报用的 HTML 表格）、「复制 AI 素材」 |
| 近期走势 | 近 8 周 / 12 周 / 半年每周末的热力图，可切换显示偏离度或周涨跌（格子颜色是强弱，边框标出当周转变）；美元指数、美债 10 年、中债 10 年、美债 2 年也列在下面；本周 vs 上周对照表 |
| 标的详情 | 点任一行进入：当前状态和信号、本轮持续和涨跌、近一月、今年来、均线方向、PE / PB 百分位（有估值时）、近一年切换次数；价格与 20 日均线走势图（YES 区间着色），偏离度柱状图，3 月 / 6 月 / 1 年 / 3 年 / 全部切换；近一年的状态特征（YES 天数占比、切换次数、YES 和 NO 的平均持续天数、最大最小偏离度）；近 12 周表；历次状态区间及每段涨跌 |
| 宏观 | 美元指数及其 20 日均线；中美国债 2 / 5 / 10 / 30 年收益率对比；中美利差（10 年、2 年）和期限利差（10 年 − 2 年）走势 |
| 周报存档 | 本周 AI 素材（精简版 / 完整版，可复制、下载、预览、看截图版）；`outputs/` 下历次 `weekly_review_*.md`、`news_candidates_*.md`，按周分组，点开直接阅读，可跳到「回看当周数据」 |
| 数据健康 | 每个标的的数据源、条数、起止日期、是否落后、近 120 天最大间隔、近 60 天单日涨跌超过 8% 的日子；美元指数、各期限国债和蛋卷估值同样列出；上次刷新的耗时和失败项 |

首次打开会有 5 步操作指引，右上角「?」可以再看。精简版 / 完整版、热力图周数、走势图区间等选择保存在浏览器里。

## 交给 AI 生成周度复盘正文

日常直接说下面这种话就够了：

- `帮我生成一下鱼盆模型周度复盘`
- `基于最新 review 输出，生成本周鱼盆模型周度复盘`
- `按 review_preferences 的偏好，写一下这周的鱼盆模型周报`

AI 按 [`prompts/鱼盆模型周度复盘模版.md`](prompts/鱼盆模型周度复盘模版.md) 开头注释里的步骤执行：刷新数据 → 读素材 → 选新闻 → 按骨架写正文。`prompts/` 下两个文件分工：

| 文件 | 内容 |
|------|------|
| `鱼盆模型周度复盘模版.md` | 操作步骤（含刷新命令、读哪个文件、输出文件名）和文章骨架 |
| `review_preferences.md` | 全部写作规则、新闻筛选和评分规则，以及历次的「已记录选择」；规则只写在这里，要改写法就改这个文件 |

周报只写本周，不和往期对比；更早的走势在网页的近期走势页和回看里看。

## 输出文件

每次更新（启动服务、点「刷新数据」或运行 `backend.update`）都会重写 `outputs/` 下的四个文件：

| 文件 | 内容 |
|------|------|
| `latest_review_simple.md` | 精简版 AI 素材：数据日期提示、股市 / 大宗商品 / 宏观三张表，加「本周变化」（本周转变的标的、来回切换的、美元和国债的周变化、中美利差和期限利差） |
| `latest_review.md` | 完整版：包含全部 36 个标的（多一张「行业与个股」表），表格多「信号」「PE 百分位」两列，文末附分档说明 |
| `latest_review_simple.html` / `latest_review.html` | 截图版：带国旗的表格。精简版用于周报配图，完整版同时是 GitHub Pages 上的日报 |

数据有缺失时，素材开头会写明哪个标的数据截至哪天、哪个取数失败，提醒 AI 不要当作最新。现在任一周的情况都可以在网页上回看，也可以用 `/api/material?asof=YYYY-MM-DD` 重新生成当周素材，所以不再按时间戳另存；旧脚本留下的 `review_*` 只在 `outputs/archive/` 保留了最后一次（2026-08-02）作参照。AI 写的 `weekly_review_*`、`news_candidates_*` 无法重新生成，要保留。`outputs/` 已 gitignore。

| PE / PB 百分位 | 蛋卷基金 `index_eva/dj` | 只给当天一条，每次刷新累积；覆盖上证50、沪深300、中证500、中证1000、创业板指、科创50、恒生、恒生科技、标普500、德国DAX、红利低波，纳斯达克综合用纳指100、印度SENSEX 用 MSCI印度作参照 |

- **鱼盆信号**：临界值 = 近 20 个交易日收盘价的平均（MA20）；收盘价高于临界值为 YES，否则为 NO；**偏离度** = 收盘价 ÷ 临界值 − 1。状态转变时间 = 当前这一段连续 YES 或 NO 的第一天。和原 yupen 日报的算法一致，替换前逐个标的核对过状态、临界值、偏离度和转变时间。
- **5 档信号**（沿用 yupen 日报）：偏离度 ≥ 3% 强力买入，1%～3% 买入，0～1% 观望（以上为 YES），−1%～0 谨慎，< −1% 卖出（以上为 NO）。只是偏离度的分段，不看估值和基本面。网页上始终显示；截图版和 AI 素材只有完整版带这一列，周报用的精简版保持原样。
- **回看**：均线只用过去的数据，所以把数据截到某一天重新算，就是那天当时看到的状态，不会用到未来数据。
- **本周 / 上周**：一周从周一开始。本周涨跌 = 最新收盘价 ÷ 上周最后一个收盘价 − 1；本周转变 = 现在的状态和上周最后一个交易日不同；来回切换 = 本周内状态变了不止一次。整周休市的标的显示「本周休市」。
- **宏观不套鱼盆信号**：国债收益率是利率不是价格，收益率上行对应债券价格下跌，套用 MA20 语义相反，所以只看水平和变化（单位基点，1bp = 0.01%）。美元指数走外汇源，给出 20 日均线作参考，但不进股市排名。
- **数据日期**：所有标的里最新的交易日。某个标的落后超过 4 个自然日，页面和素材里会提示「数据截至」；各地休市日不同，落后一两天属正常。
- **刷新保护**：某个标的这次取不到时保留上次的数据，数据健康页和素材里注明失败项；`backend.update` 的退出码为 1。
- **颜色**：沿用 A 股习惯，涨红跌绿，YES 红、NO 绿。

- 台湾加权指数最新只到 10-22：证交所官方数据同样没有 10-23，当天台股休市。

## 局限

- 日、韩、台、印、英、德指数的新浪接口只给最近约 1000 个交易日，详情页的「全部」区间和历史统计从 2022 年开始；科创50 从 2020 年、恒生科技从 2020-08 开始。
- 各地交易日不同，「本周」按自然周对齐，数据日期取所有标的里最新的一天；周五美股收盘在北京时间周六早上，周六刷新才能拿到完整一周。
- 鱼盆模型只看价格和 20 日均线，震荡市里会频繁切换（近一年切换次数可以参考；个股一年切换二十次左右很常见）；它描述的是趋势状态，5 档信号的名字沿用 yupen，也不是买卖建议。
- 蛋卷估值只能拿到当天的，从 2026-10-23 开始累积；回看更早的周时没有 PE 百分位，表格里不显示这一列。没有对应指数的标的（如上证指数、中证A500、日经225、个股）也没有估值。
- 新闻部分由 AI 检索和筛选，本项目只提供行情素材。
