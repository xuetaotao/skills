# 资产配置研究

站在人民币投资者的角度，比较全球主要大类资产的长期风险收益，并回测几种配置组合的效果，为自己的资产配置提供数据参考。

目前包含两项分析：

- **全球资产配置对比**（`global_portfolio.py`）：A股、美股、日股、英股与黄金统一换算成人民币后对比，并做组合构建与回测，输出 HTML 报告。这是本目录的主体。
- **A股指数风险收益**（`a_share_risk_return.py`）：A股主要指数的长期收益、回撤、持有期盈利概率，以及当前估值水平，作为 A 股部分的补充参考。

## 项目结构

```
stock/asset_allocation/
├── scripts/
│   ├── global_portfolio.py       # 全球资产配置对比：取数 → 统计 → 组合优化与回测 → 生成报告
│   ├── a_share_risk_return.py    # A股指数风险收益与估值，结果打印到控制台
│   ├── probe_sources.py          # 调试用：探测数据接口是否可用、历史有多长
│   └── templates/
│       └── global_portfolio.html # 报告模板，脚本把计算结果填入 __DATA__ 占位符
├── reports/                      # 留存的分析结果（入库）
├── data/                         # 行情数据缓存（已 gitignore，运行时自动生成）
└── output/                       # 中间结果 JSON 等（已 gitignore）
```

## 运行

依赖 `akshare`、`pandas`、`numpy`、`scipy`、`requests`：

```bash
pip install akshare pandas numpy scipy requests
```

在本目录下运行（`data/`、`output/`、`reports/` 的位置按脚本自身路径确定，从其他目录运行也不会写错地方）：

```bash
# 全球资产配置对比：生成 reports/YYYY-MM-DD-全球资产配置对比.html
python scripts/global_portfolio.py

# A股指数风险收益：结果打印到控制台
python scripts/a_share_risk_return.py
```

如果想把 A 股分析结果留存到 `reports/`，在 Windows PowerShell 下建议这样保存，避免默认的 `>` 写成 UTF-16（git 会把它当成二进制文件）：

```powershell
python scripts/a_share_risk_return.py | Out-File -Encoding utf8 "reports/$(Get-Date -Format yyyy-MM-dd)-A股指数风险收益.txt"
```

几点说明：

- `global_portfolio.py` 会把行情缓存到 `data/`：价格和汇率 12 小时内不重复下载，股息率 7 天内不重复下载。想强制刷新，删掉 `data/` 再运行即可。
- 报告按运行日期命名，同一天重复运行会覆盖当天的报告。
- 数据源更新后，重新运行得到的数字会与已留存的报告略有不同，这是正常的。
- 数据接口偶尔会失效或改版，可以先运行 `python scripts/probe_sources.py` 排查。

## 全球资产配置对比的口径

| 资产 | 数据 | 是否含分红 |
|------|------|-----------|
| 沪深300 / 中证500 / 中证1000 / 中证红利 | 中证指数官网全收益指数 | 含 |
| 创业板指 / 科创50 | 价格指数 | 不含 |
| 标普500 | `^SP500TR` 全收益指数（Yahoo） | 含 |
| 纳指100 | QQQ 复权价（Yahoo） | 含，已扣基金费率 |
| 日经225 | `^N225` 价格 + 1321.T 实际股息率估算 | 近似 |
| 富时100 | `^FTSE` 价格 + ISF.L 实际股息率估算 | 近似 |
| 黄金 | 伦敦金现货（新浪外盘） | — |
| 汇率 | 中国银行折算价（新浪），统一换算为人民币 | — |

统计基于 2006-11 起的月末数据，组合按月再平衡，不计交易成本和税费。

报告中的组合分三类，解读时要区分：

- **事先设定的组合**：等权、均衡配置，以及单一资产基准（100% 沪深300、100% 标普500）。
- **全样本优化**（最小方差、最大夏普、风险平价）：用全部历史数据求权重，含后视镜偏差，实际无法复制，只能说明“事后看最优大概长什么样”。
- **滚动优化**：每年末只用过去 60 个月的数据估计权重，持有下一年，更接近真实可执行的效果。

## 局限

- 日经225、富时100 的分红是用 ETF 股息率估算的，不是官方全收益指数。
- 创业板指、科创50 历史较短且不含分红，没有纳入相关性分析和组合优化。
- 结论依赖样本区间。过去 20 年的收益、波动和相关性不代表未来，尤其是美股的强势与 A 股的估值环境都可能改变。
