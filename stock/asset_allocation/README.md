# 全球资产配置台

站在人民币投资者的角度，回答两个问题：

1. **我的钱应该怎样在 A 股、海外股票、债券和黄金之间分配？**
2. **现在需不需要调整？**

本地运行的小网站：双击启动，每次启动时自动更新数据，浏览器里查看结论、拖动权重做回测、对照自己的持仓算出买卖金额。

## 快速开始

```bat
scripts\start_server.bat
```

脚本会启动服务并自动打开 <http://127.0.0.1:8322>。首次运行需要下载近 20 年的数据，大约 3–5 分钟（中国银行汇率接口较慢），页面会显示进度，完成后自动刷新。之后每次启动都会在后台增量更新（不影响浏览旧数据），运行期间可随时点右上角「刷新数据」。

Python 解释器按以下顺序查找：项目下的 `.venv` → WorkBuddy 自带环境 → 系统 PATH 中的 `python`。缺少依赖时脚本会提示安装命令：

```bash
pip install -r requirements.txt
```

## 页面

| 页面 | 用途 |
|------|------|

| 资产对比 | 长期风险收益表（含汇率贡献）、净值走势、日历年收益方格、相关性热力图；点击资产看详情（人民币 vs 本币、回撤、汇率） |
| 组合实验室 | 拖动滑块调权重，实时回测年化、回撤、最差一年、风险贡献、逐年收益；可载入预设或滚动优化的最新权重；保存为“我的目标组合” |
| 我的持仓 | 录入各资产持有金额，显示与目标的偏离、再平衡买卖金额、新增资金的分配方案。**数据只保存在浏览器 localStorage，不上传** |
| A股估值 | 沪深300 估值结论、主要指数滚动市盈率分位、股债利差、10 年国债、股息率 vs 国债、持有期盈利概率、申万行业估值 |

## 资产与口径

所有收益均为**人民币计价**，统计区间从 2006-11（伦敦金数据的起点）开始，月末数据，组合按月再平衡，不计交易成本、税费和 QDII 溢价。

| 资产 | 数据 | 收益口径 | 汇率 |
|------|------|---------|------|
| 沪深300 / 中证500 / 中证1000 / 中证红利 | 中证指数官网全收益指数 | 含分红 | — |
| 中证A500 | 中证官网 `000510CNY010` 全收益指数（2024-09 发布，之前为回溯数据） | 含分红 | — |
| 创业板指 | 新浪 `sz399606` 创业板R（全收益），2010-06 起 | 含分红 | — |
| 科创50 / 科创创业50 | 中证官网价格指数，2020-01 起（没有可取的全收益指数） | 不含分红（股息率约 0.3% / 0.7%） | — |
| 中证全债 | 中证指数官网 H11001 | 含票息 | — |
| 标普500 | Yahoo `^SP500TR` | 全收益 | 中行美元折算价 |
| 纳指100 | Yahoo QQQ 复权价 | 含分红、已扣费 | 中行美元折算价 |
| 日经225 | `^N225` + 1321.T 股息率 | 估算 | 中行日元折算价 |
| 富时100 | `^FTSE` + ISF.L 股息率 | 估算 | 中行英镑折算价 |
| 德国DAX | `^GDAXI`（DAX 本身是全收益指数） | 全收益 | 中行欧元折算价 |
| 恒生指数 | `^HSI` + 2800.HK 股息率 | 估算 | 中行港币折算价 |
| 台湾加权 | `^TWII` + 0050.TW 股息率 | 估算 | 美元折算价 ÷ Yahoo USD/TWD |
| 韩国KOSPI | `^KS11` + 069500.KS 股息率 | 估算 | 美元折算价 ÷ Yahoo USD/KRW |
| 黄金 | 伦敦金现货（新浪） | — | 中行美元折算价 |

- **股息估算**：Yahoo 的 ETF 分红记录约从 2013 年开始。各年分红合计 ÷ 当年均价得到股息率，当年用近 12 个月；按交易日均匀计入价格指数，缺失年份用中位数代替。
- **A 股估值结论**：便宜程度 =（1 − 沪深300 滚动市盈率近 10 年分位 + 股债利差近 10 年分位）÷ 2。≥0.75 低估，≥0.6 偏低，≤0.25 高估，≤0.4 偏高，其余适中。
- **滚动优化**：最小方差、风险平价、最大夏普。每年末只用过去 60 个月数据估计权重（单资产上限 35%），持有下一年。只作参考，不建议照抄。
- **历史较短的资产**（创业板指、科创50、科创创业50）可以进组合：
  - 实验室和持仓页的回测从所选资产都有数据的月份开始，并提示是哪个资产限制了起点；
  - 相关系数按每两个资产的共同区间计算；
  - 滚动优化在某资产攒够 60 个月数据后才纳入候选（创业板指 2016 年起，科创两只 2025 年起）；
  - 示例组合和“等权”预设只用 2006 年起就有数据的资产，保持 20 年的回测区间。
- **坏点处理**：日度序列中相对前值跳变超过阈值（价格 25%、汇率 10%）且几天内回到原水平的点，分析时剔除，原始数据不改，在「数据健康」页列出。

## 命令行

```bash
python -m backend.update                # 增量更新全部序列和估值快照（也可双击 scripts\update_data.bat）
python -m backend.update HSI FX_USD     # 只更新指定序列
python -m backend.update --full HSI     # 清空后全量重建指定序列
python scripts/probes/probe_sources.py  # 探测各数据接口是否可用（不写数据库）
```

某个序列抓取失败时，数据库保留之前的数据，页面右上角和「数据健康」页会标出。设置环境变量 `ASSET_AUTO_REFRESH=0` 可关闭启动时的自动更新。

## 项目结构

│   └── server.py      # FastAPI：页面、数据接口、后台刷新
├── frontend/          # 单页应用（原生 JS + ECharts）
├── scripts/
│   ├── start_server.bat
│   ├── update_data.bat
│   └── probes/        # 数据接口探测

├── data/              # assets.db（已 gitignore，首次启动自动生成）

## 局限

- 五个市场的分红为估算值，不是官方全收益指数；科创50、科创创业50 不含分红。
- 中证A500 2024 年以前是回溯数据，成分按事后规则选出，历史表现可能偏乐观。科创两只指数只有 2020 年以来约 7 年数据，正好覆盖一轮成长股牛熊，统计结果受这段行情影响很大。
- 结论依赖样本区间。过去 20 年的收益、波动和相关性不代表未来。
- 估值只决定长期赔率，不决定短期涨跌。
