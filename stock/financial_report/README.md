# 财报追踪台

盯住自己关心的几家 A 股公司：每次打开都能看到它们**最新一期财报的关键数字**、**在同行业里处在什么位置**、**有哪些值得留意的变化**。

本地运行的小网站：双击启动，每次启动时自动更新数据。默认自选股是国有六大行（工、农、建、中、交、邮储），可以随时增删任何 A 股公司——银行、保险、券商或一般企业都行，指标会按公司类型自动切换。

## 快速开始

```bat
scripts\start_server.bat
```

脚本会启动服务并自动打开 <http://127.0.0.1:8323>。首次运行会下载自选股及其同行业公司的历年财报、2018 年以来的估值和分红记录，大约半分钟到一分钟，页面显示进度，完成后自动刷新。之后每次启动都会在后台更新（不影响浏览旧数据），运行期间可随时点右上角「刷新数据」。

Python 解释器按以下顺序查找：项目下的 `.venv` → WorkBuddy 自带环境 → 系统 PATH 中的 `python`。缺少依赖时脚本会提示安装命令：

```bash
pip install -r requirements.txt
```

列表 / 卡片、分组和排序记在浏览器里。从详情页返回（浏览器后退或点「总览」）会回到离开时的位置，并闪一下刚才看的那只；页面滚动较长时右下角有「回到顶部」按钮。

**自选股**：在总览页搜索框输入代码、名称或拼音首字母（如 `600519` / `茅台` / `gzmt`），回车或点击结果添加；拖动标签排序，点 × 移除。列表保存在本地数据库 `data/financial.db`，清空后不会自动补回默认的六大行。添加时先同步校验能取到财报，再在后台下载它的同行业、估值和分红数据。

## 数据与口径

| 数据 | 来源 | 说明 |
|------|------|------|
| 财务指标 | 东方财富 F10「主要指标」`RPT_F10_FINANCE_MAINFINADATA` | 按公司类型返回银行 / 保险 / 证券 / 一般企业的专项字段；每次刷新整段重下（东财会修订历史数据） |
| 当日估值 | 东方财富 `RPT_VALUEANALYSIS_DET` | 收盘价、市盈率 TTM、市净率 MRQ、总市值 |
| 估值历史 | 同上，2018 年起 | 只为自选股下载，之后增量更新 |
| 日收盘价 | 同上，近 5 年 | 自选股和同行业全部下载（不复权），之后增量更新，算区间涨跌幅 |
| 复权因子 | 新浪财经后复权因子 `hfq.js` | 等比复权，含现金分红、送转、配股；每只股票每天最多取一次 |
| 企业性质 | 东方财富 F10 公司概况 `RPT_F10_ORG_BASICINFO` | 企业性质、控股股东、实际控制人、上市日期，每次刷新一并更新 |
| 分红 | 东方财富 `RPT_SHAREBONUS_DET` | 每 10 股税前派现；股息率只计已实施的现金分红，按财年汇总时含已公告的预案 |
| 10 年期国债收益率 | 东方财富 `RPTA_WEB_TREASURYYIELD`（字段 `EMM00166466`） | 中债国债到期收益率，近 5 年，之后增量更新，算股债利差 |
| 行业分类 | 申万宏源研究 `StockClassifyUse_stock.xls` + 巨潮资讯行业名称 | 每周检查一次 |
| 搜索 | 东方财富代码表，失败时用新浪 suggest | 只返回沪 A、深 A、京 A |

- **报告期累计**：A 股利润表从年初累计到报告期末（中报 = 1–6 月），所以增速、ROE 都只和上年同一报告期比。ROE 是累计值，没有年化。
- **单季**：本期累计 − 同年上一期累计，一季度即一季报本身；缺少同年上一期时不拆。
- **同行业**：申万一级不超过 60 家就整个一级一起比（如银行 42 家，再按二级分成国有大行 / 股份行 / 城商行 / 农商行）；否则用二级（如白酒），二级超过 80 家用三级（如水力发电）。剔除当日没有估值的公司（退市、长期停牌），最多保留市值前 80 家，自选股始终保留。
- **排名与中位数**：同一报告期、同组公司之间比较；「越低越好」的指标（不良率、负债率、周转天数）按从低到高排。
- **估值分位**：2018 年以来每日估值中不高于当前值的比例，需要至少 250 个交易日；市盈率只统计正值。金融类公司看市净率，其余看市盈率。
- **股息率 TTM**：最近一次已除息分红所属报告期往前一年内（四个季度）的每股派现 ÷ 最新收盘价。按报告期而不是除息日统计，避免一年分两次的公司（如工行）在 12 个月里出现三次除息而虚高；最近一次分红的报告期超过 2 年时不计（年度分红从报告期末到下一次除息常超过 18 个月）。从只分年度改为一年两次的那一年，上一年的全年分红按窗口覆盖的月份折算、但不低于全年金额，避免出现半年的虚高（工行 2025 年上半年曾因此被算成 6.8%）。
- **股息率分位与股债利差**：用近 5 年的日收盘价和分红记录，逐日算出当时已知的股息率 TTM，当前值在其中的位置就是分位，越高说明相对分红股价越便宜（与估值分位方向相反）。股债利差 = 股息率 − 当天的 10 年期国债收益率，同样给出近 5 年分位。截至 2026-10-23：工行股息率 3.85%，处于 2021 年以来的 5% 分位（中位数 5.70%）；10 年期国债 1.64%，利差 +2.21 个百分点。当前没有分红的公司不算分位。
- **分红率与连续分红**：某财年的每股分红合计（中期 + 三季度 + 年度，含已公告的预案）÷ 当年年报的基本每股收益；年报未出的财年标为「进行中」，不算分红率。连续分红年数从最近一个有年报的财年往前数，数到最早有数据的年份时显示「≥」。每股分红 3 年增速是最近一个完整财年相对 3 年前的年化。送转、增发会摊薄每股金额（如 2025 年财政部注资后，交行、邮储每股分红下降）。
- **区间涨跌幅**：期末复权价 ÷ 期初复权价 − 1，复权价 = 不复权收盘价 × 当日适用的后复权因子，相当于分红在除息日再投入，即持有期总收益；同时给出不复权的纯股价变化，两年及以上的区间另给年化。终点是最新交易日，起点是回看日（近 1 周 = 7 天前，近 N 月 / 年按日历月倒推）当天或之前最近一个交易日，今年以来从上年最后一个交易日算起；上市晚于回看日的区间留空。高分红股票两者差别很大：截至 2026-10-23，工商银行近 5 年股价 +75.90%，含分红 +132.49%（与用分红记录逐笔推算的结果一致）。东方财富行情接口的前 / 后复权是加减法复权（工行同一区间算出 +171.90% / +68.41%），不能用来算长区间收益。
- **企业性质**：东方财富 F10 的原值归成六类——央企（央企子公司、中央金融企业）、地方国企（地方国有企业）、其他国企、民企（大型民企、中小微民企、民营企业）、外资 / 港澳台（中外合资、外商独资、港澳台、境外中企等）、其他（其他企业、集体企业）。这是数据商的判断，股权分散的公司可能有争议：招商银行没有控股股东，招商局集团（央企）旗下公司合计持股最多，东财却归为地方国企；平安银行、民生银行归为「其他」。悬停标签可看控股股东和实际控制人。
- **一次性损益**：归母净利与扣非净利的同比增速相差 10 个百分点以上、且某一期非经常性损益占归母净利 10% 以上时，认为增速被一次性因素扭曲，利润类结论改按扣非净利判断，页面上归母增速旁标出扣非增速。例：粤高速A 2026 中报归母净利同比 −19.58%，但 2025 年一季度子公司广佛高速转回代垫管养支出坏账准备 3.43 亿（归母影响 2.58 亿），剔除后扣非净利同比 +5.99%，结论是“提示”而不是“风险”；同期的 ROE 下降同样标为受基数影响。
- **自动结论**分四级：风险 / 留意 / 积极 / 提示。规则见 `backend/analytics.py` 的 `signals()`，主要包括利润增速转负、放缓或加快，最新单季利润下滑，营收下降，ROE 相对变化超过 10%，银行的不良率（±基点）、拨备覆盖率、净息差、核心一级资本，保险的新业务价值和偿付能力，券商的风险覆盖率，一般企业的毛利率、现金含量、负债率，估值分位 ≤20% 或 ≥80%，股息率 ≥5%，股息率分位 ≥80% 或 ≤20%（与估值分位同向时合并成一条），分红率超过 100% 或亏损仍分红，每股分红同比减少 10% 以上或上一财年停止分红，股价与技术面（见下），行业前后 20%，新披露与待披露。每条结论带类别（财报 / 估值 / 股息 / 股价 / 技术 / 行业 / 披露）；个股页“风险与机会”把风险、留意归为风险组，积极归为机会组，提示和披露类放在“其他提示”。总览列表和卡片只显示最重要的几条。
- **技术面**（`tech_state()`）：只有日收盘价，没有成交量和日内高低价，所以只做收盘价能判断的事，全部用后复权价（分红除息不造成断档）。趋势：收盘价在年线（250 日均线）上方且 20 日 > 60 日 > 年线为上升，反过来为下降，其余为震荡——趋势只作为标签显示，不单独成为结论（普涨或普跌时几乎每只都会报）。结论只报“刚发生的变化”和极端状态：最近 10 个交易日站上 / 跌破年线（离年线不足 1% 的不算），收盘价接近一年最高 / 最低（一年高低点在最近 5 个交易日内），较一年高点回撤 ≥20%（≥30% 为风险），近 5 个交易日跌 ≥8%（≥15% 为风险）或涨 ≥12%，高于年线 30% 以上，14 日 RSI ≥75 超买 / ≤25 超卖，近 3 个月涨跌幅与同行业中位数相差 15 个百分点以上。
- **综合判断**（`insight()`）：把估值、股息、财报和股价放在一起，按顺序匹配第一条：估值低位或高股息、但利润明显下滑（同比 ≤ −10% 或有财报类风险结论）或分红不可持续 → 价值陷阱提示；估值高位配业绩下滑；业绩和股价一起走弱；业绩下滑而股价处于上升趋势（背离）；估值高位或股息率低位（≤20% 分位）、股价又很强（创一年新高、超买、远高于年线或一周急涨）→ 追高性价比低；便宜且趋势向上；便宜但仍在下跌 → 分批、等企稳；业绩增长 ≥10% 而股价走弱 → 下跌不是财报原因；业绩和股价共振向上；便宜、无明显趋势。利润增速被一次性损益扭曲时按扣非净利判断。截至 2026-10-23：工、建、中、交四大行股价创一年新高，股息率降到近 5 年 0%–5% 分位，提示“追高的性价比下降”；中国电信市盈率处于 95% 分位、三季报归母净利同比 −14.8%，提示“估值和业绩背离”。

## 银行财报的口径陷阱

来自 2026 年 8 月银行中报研报的核对经验，引用数据时要先对齐口径：

- **净利润 vs 归母净利润**：增速常常不同，少数股东损益为负时差异更大。例：光大银行 2026 中报归母净利 187.11 亿（−24.01%），全口径净利润 188.38 亿（−23.86%）。本站统一用归母净利润。
- **营业收入的两个口径**：工行 2026 中报“营业收入” 4658.59 亿 vs “经营收入” 4461.63 亿。本站用东财的营业总收入（4658.59 亿）。
- **净息差媒体口径冲突**：工行 2026 中报媒体出现过 1.27% / 1.29% 两个值，发布会确认 1.29%，与东财数据一致。
- **币种**：渤海银行同时披露人民币和港币口径（人民币 41.51 亿 / +8.37%，港币 47.79 亿 / +13.78%），以人民币为准。
- 未上市银行（如恒丰、广发）没有公开中报，不在 A 股数据里。

## 研报与公众号草稿

`reports/` 里是此前手工制作的研报（2026-08-30 银行中报对比、数据核对附页、两篇公众号草稿及其图表 PNG），会显示在网站的「报告」页。`reports/` 已加入 `.gitignore`，只保存在本地。再做类似产出时可复用的经验：

- **公众号草稿**：整篇用内联 CSS（编辑器会剥离 class 和外链样式）；图表必须是 PNG（不支持 ECharts 动态图），以相对路径 `<img src="charts/chartN.png">` 嵌入，2 倍尺寸更清晰。在浏览器打开草稿 → 全选复制 → 粘贴进公众号后台，图片会自动转存。由本人审校后发布。
- **ECharts 图转 PNG**：Node 里 `echarts.init(null, null, { renderer: 'svg', ssr: true, width: 680, height: 400 })`，关闭动画、字体设为 Microsoft YaHei，`renderToSVGString()` 后用 `@resvg/resvg-js` 渲染（`fitTo: { mode: 'width', value: 1360 }`、`loadSystemFonts: true`、白底）。
- **双轴柱线图标签防重叠**：柱标签 `insideTop` 白字；线标签 `position: 'bottom'` 同色加粗、白色描边；必要时给右轴设 `max` 把线压到柱身中部。极矮的柱子逐项改成柱顶外侧深色字；含负值的增速图正值标签放柱顶上方、负值放柱底下方。所有标签 `formatter` 用 `toFixed(2)`，否则 ECharts 会吃掉末尾的 0（1.00 → 1）。
- **交付前自检**：覆盖对象是否全（图表的公司数等于全集，缺项要在图注说明）；对称的分组是否都有对应图表；表格逐列扫一遍，“—”只用于确认未披露的项；同一指标在研报表格、图表数据、草稿正文、图注四处同值同口径；改表格行时核对列头顺序（曾把净息差误填进拨备列）。

`reports/2026-09-03-债券利率风险笔记.md` 是一份与本项目无关的学习笔记（加息降息与债券价格、久期、凸性），从旧的 WorkBuddy 记忆中原样保留。

## 命令行

```bash
python -m backend.update                # 更新全部自选股及其同行业（也可双击 scripts\update_data.bat）
python -m backend.update 600900 600519  # 只更新指定股票及其同行业
python scripts/probes/probe_sources.py  # 探测各数据接口是否可用（不写数据库）
```

某家公司抓取失败时，数据库保留之前的数据，页面右上角和「数据健康」页会标出。设置环境变量 `FIN_AUTO_REFRESH=0` 可关闭启动时的自动更新（数据库为空时仍会初始化）。

## 局限

- 东财 F10 的专项指标并非每家公司每期都有：净利差、新业务价值等很多公司只在中报、年报披露；部分券商（如东方财富）被东财归为一般企业，不出现在券商专项指标的排名里。
- 区间涨跌幅最长 5 年；新浪复权因子取不到时沿用上次的因子（之后新除息的分红暂不计入），从未取到的股票涨跌幅留空，「数据健康」页会标出。
- 股息率分位只覆盖近 5 年，这几年 10 年期国债收益率从约 2.9% 降到 1.6%，公用事业股的股息率分位和股债利差分位可能差很多，两个都看；分红是税前口径，个人持股不满 1 年还要扣红利税。
- 估值历史只从 2018 年开始，分位反映的是这几年的区间；行业逻辑变化（如银行息差持续下行）后，历史区间不一定还适用。
- 同行业按申万分类机械划分，业务差异大的公司（如多元化集团）可能被放在一起比。
- 自动结论是规则判断，只提示“哪里变了”，不解释原因，也不代表好坏的最终结论。
- 技术面没有成交量和日内高低价，放量突破、缩量回调、K 线形态（如长上影线、跳空缺口）这类判断做不了；均线、新高新低这些信号在震荡市里容易反复出现，要结合财报和估值看。综合判断只覆盖几种典型组合，没有匹配到的股票不给结论。
