# ETF 规模筛选

列出沪深两市**全部上市 ETF 的最新规模**，按规模门槛筛选，并**按跟踪指数去重**（同一个指数只保留规模最大的一只），帮你快速找到每个方向上最主流的那只 ETF。每只 ETF 标出**类型**（宽基、窄基、策略、利率债等），带**区间收益**（近 1 周到近 3 年，含同类中位数和排名），宽基指数还有**估值分位**（滚动市盈率在近 10 年里的位置）；每天的快照积累下来，还能看规模变化和资金流向。

本地运行的小网站：双击启动，每次启动时自动更新数据。原先放在 `stock/financial_report/etf_data/` 下的一次性脚本（产出 2026-09-05 的「规模超 50 亿 ETF 清单」）已由本项目取代。

## 快速开始

```bat
scripts\start_server.bat
```

脚本会启动服务并自动打开 <http://127.0.0.1:8324>。首次运行会下载两个交易所的 ETF 列表、份额和最新价格，从中证、国证官网补齐指数名称和类别，再取区间收益和宽基指数近 10 年的估值，大约一两分钟，完成后页面自动刷新。之后的刷新只补新数据，半分钟到一分钟。之后每次启动都会在后台更新并保存当天快照，运行期间可随时点右上角「刷新数据」。

Python 解释器按以下顺序查找：项目下的 `.venv` → WorkBuddy 自带环境 → 系统 PATH 中的 `python`。缺少依赖时脚本会提示安装命令：

```bash
pip install -r requirements.txt
```

## 页面

| 页面 | 用途 |
|------|------|
| 清单 | 规模门槛（默认 50 亿，可改）、按指数去重开关、分类筛选（A股 / 港股 / 海外 / 债券 / 商品 / 货币）、类型筛选（宽基 / 窄基 / 策略 / 利率债 / 信用债 / 可转债 / 黄金 / 其他商品 / 货币）、搜索；汇总（只数、合计规模、门槛附近有多少只、分类占比）；明细表三种显示——**规模**（份额、规模变化、净申赎）、**收益**（近 1 周到近 3 年、成立来，底部是筛选结果的中位数）、**估值**（宽基指数的滚动市盈率、分位、中位数、20%–80% 分位、历史区间）；可排序，可导出 CSV（含收益和估值） |
| ETF / 指数详情 | 点击清单任一行进入：跟踪同一指数的全部 ETF，可在**规模**（规模、占比、份额、成交额、规模变化、上市日期）和**收益**（各区间收益，底部是同类中位数和同类排名）之间切换，切换与清单页的「显示」共用；规模对比图，规模走势；宽基指数的估值卡片（分位、历史区间、市盈率走势图） |
| 资金流向 | 近 1 周 / 1 月 / 3 月的净申赎：按分类汇总（拆成资金进出与价格涨跌两部分）、净流入和净流出最多的指数、按指数汇总表 |
| 数据健康 | 各来源的条数和日期、与腾讯行情的交叉核对、补充和推断的数据（货币 ETF 份额、查不到名称的指数、按名称判断类型的指数、没有估值的宽基）、本地快照列表 |
| 术语 / 报告 | 术语解释（正文虚线词悬停也可看）；`reports/` 下留存的报告 |

门槛、去重、分类、类型、显示方式和变化窗口保存在浏览器里，下次打开还在。

## 数据与口径

| 数据 | 来源 | 说明 |
|------|------|------|
| 上交所 ETF 列表 | 上交所 `commonSoaQuery.do?sqlId=FUND_LIST&fundType=00` | 代码、简称、管理人、跟踪指数代码和名称、子类别（subClass）、上市日期 |
| 上交所份额 | 上交所 `commonQuery.do?sqlId=COMMON_SSE_ZQPZ_ETFZL_XXPL_ETFGM_SEARCH_L` | 按统计日查询，单位万份；**不含货币 ETF**；支持查历史日期 |
| 深交所 ETF 列表与份额 | 深交所 `ShowReport?CATALOGID=1945`（ETF 列表）+ `1105`（基金列表） | 拟合指数、当前规模（份）、管理人；投资类别和上市日期来自基金列表；**只有当天份额，没有历史** |
| 价格与成交额 | 新浪财经 ETF 行情（akshare `fund_etf_category_sina`） | 非交易时间是最近一个交易日的收盘价 |
| 交叉核对 | 腾讯行情 `qt.gtimg.cn`（GBK，`f[45]` 为总市值，单位亿元） | 核对规模最大的 300 只 |
| 指数名称与类别 | 中证指数 `query-index-item`（`indexClassify`）、国证指数 `indexList`（`indextype` 末两位：00 规模、01 行业、02 风格、03 主题、04 策略、05 综合） | 每周更新一次 |
| 黄金 ETF 跟踪标的 | 东方财富基金 F10 `jbgk_<代码>.html` 的“跟踪标的” | 只用于上交所黄金 ETF，结果缓存 |
| 区间收益 | 东方财富场内交易基金排行（akshare `fund_exchange_rank_em`） | 一次取约 1690 只；按复权净值，含分红；近 1 周、1 月、3 月、6 月、今年来、近 1 年、2 年、3 年、成立来；净值通常是上一交易日的 |
| 宽基估值（中证系列） | 中证指数 `perf/index-perf` 的 `peg`（滚动市盈率） | 每日数据，2011 年起；首次取近 10 年，之后只补新日期 |
| 宽基估值（深证、国证系列） | 乐咕乐股 `api/stockdata/index-basic-pe`（`addTtmPe`，市值加权滚动市盈率；token、cookie 用 akshare 的 `get_token_lg`、`get_cookie_csrf`） | 月末数据 + 最新一天；创业板指、创业板50、深证100、国证2000 等，深证成指等没有收录；有限流，每只间隔 3 秒 |

- **规模 = 份额 × 最新价**（市值口径）。基金定期报告的“净资产规模”滞后一个季度左右，两者可能相差 10% 以上：2026-09 沪深300ETF华泰柏瑞市值口径 1067.25 亿，6 月末净资产口径 948.72 亿。
- **按指数去重**：每只 ETF 有一个规范的指数代码，同代码的 ETF 视为同一组，组内按规模排序。深交所行情系列代码（如 399300、399975）按名称归一化后对到中证官方代码（000300、399975 不变），两个交易所跟踪同一指数的 ETF 才能合并。“红利低波”与“红利低波100”、“黄金9999”与“上海金”是不同指数，不合并。
- **黄金**：深交所给出 AU9999 / SHAU 代码，上交所黄金 ETF 没有指数代码，按东财 F10 的跟踪标的区分。
- **分类**：上交所按 subClass（股票、债券、货币、商品、跨境），深交所按基金列表的投资类别，其中“其它基金”里名称像商品的（黄金、豆粕、能源化工等，不含“黄金股”）归商品，其余归海外。之后名称或指数含“港股、恒生、香港”的 A股 / 海外 ETF 归为港股。**不用“中华交易服务”判断**：中华半导体芯片指数（990001）的成分股是沪深 A 股。
- **货币 ETF**：没有跟踪指数，各自单独成组；上交所份额接口不含货币 ETF，规模直接取腾讯行情的总市值，份额 = 总市值 ÷ 价格。
- **查不到名称的指数**：交易所只给代码、中证国证官网也没有的（多为境外指数，如标普、纳斯达克、日经系列），名称用 ETF 简称去掉“ETF + 管理人”代替，页面上标 `*`；去重仍按代码，不受影响。
- **快照与变化**：每次刷新保存当天全部 ETF 的份额、价格、规模，同一天多次刷新只保留最后一次（深交所注明 T 日晚间的份额仅供参考、以 T+1 日早间为准，次日再刷新会自动修正）。变化窗口取不晚于“快照日 − N 天”的最近一次快照作基期。**净申赎 = (本期份额 − 基期份额) × 本期价格**，剔除了价格涨跌；规模变化 − 净申赎 ≈ 价格涨跌带来的部分。
- **类型**：股票类（A股、港股、海外）先看中证 / 国证官网的指数类别——规模 → 宽基，行业、主题 → 窄基（页面上仍显示具体是行业还是主题），策略、风格 → 策略。官网查不到的（主要是港股、海外指数）按名称关键词判断，顺序为策略（红利、低波、价值、成长、质量、现金流等）→ 宽基（纳指100、标普500、恒生指数、恒生中国企业、日经225、德国DAX 等）→ 行业（银行、证券、医药、消费、半导体等），都不中算主题，结果列在数据健康页方便核对。债券按名称分利率债（国债、政金债、地方债）/ 可转债 / 信用债，商品分黄金 / 其他商品（豆粕、能源化工、有色等），货币单列。
- **同指数代码的镜像**：中证把“中证100”改名“中证A100”后，深交所行情代码 399903 按名称对不上 000903；对 3999xx 这类中证官网和国证官网都查不到的代码，如果 0009xx 存在就视为同一指数。
- **区间收益**：直接用东财按复权净值算好的涨跌幅（含分红再投资），近 2 年、近 3 年页面上另算年化 = (1 + 累计)^(1/年数) − 1。东财返回少于 500 只时本次不写入。**同类** = 分类和类型都相同的指数（如“A股 · 宽基”46 个），每个指数取规模最大的一只 ETF，算中位数和排名（从高到低）；同一指数的其他 ETF 不重复计入。
- **估值分位**：只算宽基。取近 10 年的滚动市盈率（只用正值），分位 = 历史上 ≤ 当前值的点数 ÷ 总点数；指数发布不到 10 年的用全部历史，不到 1 年的不算分位。同时给出中位数、20% / 80% 分位、最低、最高。页面上 ≤ 20% 标“低位”，≥ 80% 标“高位”。中证系列是日数据，乐咕乐股是月末数据，分位口径略有不同，页面会注明。已确认没有数据的指数一周内不再重复请求。
- **刷新保护**：交易所列表、份额或价格任何一项取不到、或列表明显不全（少于 300 只）时，本次不写入，保留上一次的数据。区间收益或估值取不到时不影响规模数据，沿用上一次的结果并在刷新提示和数据健康页列出。

## 取数踩过的坑

来自 2026-09 旧脚本的经验（当时用东方财富和腾讯拼数据），换成交易所官方数据后大多已规避，留作参考：

1. **东方财富 ETF 板块 MK0021–MK0024 不含债券 ETF**：只拉这 4 个板块会漏掉全部债券 ETF（当时漏了 48 只超过 50 亿的，最大的短融ETF海富通 851 亿）。本项目直接用交易所的全量列表。
2. **腾讯行情批量查询会丢行**：一次拼 40 只，119 只只返回 60 只。`tencent_mcap()` 先批量、再逐只补查缺的。
3. **规模两个口径相差可达 12%**：见上文“数据与口径”。
4. **未上市的新 ETF**：新发行、尚未上市的 ETF 没有行情，规模只有几亿，不应计入。交易所列表只含已上市的，新浪行情也能对上（目前没有缺价格的）。
5. **港股关键词只用“港股、恒生、香港”**，见上文“分类”。
6. **网络限制（本机）**：`push2.eastmoney.com` 被拦截，只能用延时节点 `push2delay.eastmoney.com`；`fundmobapi.eastmoney.com` 首次请求后就被限流（返回空）；`hq.sinajs.cn`、雪球、蛋卷返回 403；集思录未登录只返回 20 条。
7. **50 亿边界很拥挤**：45–55 亿之间去重前有二三十只，门槛差一点结果就不同（2026-09 时上海国企ETF 50.81 亿入选、恒生医疗ETF 49.88 亿落选）。清单页的“门槛上下 10% 内”就是提示这个。

## 局限

- 交易所不提供历史份额（深交所完全没有，上交所可以按日期查），规模变化和资金流向只能从开始使用起积累；隔很久才打开一次时，变化窗口会用更早的快照，页面会注明对比的是哪一天。
- 去重只看指数代码：指数增强 ETF（如沪深300增强）以原指数为基准，会和普通指数 ETF 分在一组；跟踪同一主题但指数不同的（如几种“红利”指数）不会合并。
- 不含费率、跟踪误差、折溢价，选同指数 ETF 时这些也要看；LOF、ETF 联接基金不在范围内。
- 价格来自新浪行情，盘中刷新得到的是实时价，规模会随行情波动；份额仍是上一交易日的。
- 区间收益是净值收益，不含场内折溢价；数据由东方财富计算，本项目不做核对。
- 估值只覆盖 A 股宽基和少数中证编制的港股通宽基：纳指100、标普500、恒生指数、日经225 等港股、海外指数没有公开的历史估值来源；深证成指、深证300、北证50 等乐咕乐股也没有收录。乐咕乐股是月末数据且有限流，偶尔个别指数这次取不到，下次刷新会补上。中证A500、中证2000 等新指数历史只有两三年，分位参考意义有限。
- 类型的边界有主观成分：恒生科技、中概互联等按名称归为主题（窄基），红利类算策略不算宽基；关键词判断的结果可在数据健康页核对。
